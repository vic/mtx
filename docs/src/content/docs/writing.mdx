title: Writing
description: Send, reply, edit, delete, react.

![reply](/demo/reply.gif)

| Key | Does |
|---|---|
| `i` | type a new message |
| `enter` | send |
| `esc` | back to normal; drops the reply or edit |
| `a` | reply to the selected message |
| `A` | reply, quoted in the text |
| `e` | edit my selected message |
| `D` | delete my selected message (no confirm: the shift is the confirm) |
| `r` then `1`-`9` | quick reaction (`rr` is 👍) |
| `:name` then `tab` | emoji by shortcode |
| `m` on a selected line | menu of everything you can do with it |
