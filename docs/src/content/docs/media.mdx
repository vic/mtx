---
title: Media
description: View, open and upload images and files.
---

![image](/demo/image.gif)

| Key | Does |
|---|---|
| `v` | view: open the selected line's media or link (also `gx`) |
| `F` | letter on each line; type it to open its link or media |
| `:view` | show the image in a popup |
| `:open` | download and open the media |
| `:upload <path>` | send a local file (encrypted in encrypted rooms) |
