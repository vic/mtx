---
title: Threads and pins
description: Follow threads and pinned messages.
---

![threads](/demo/threads.gif)

| Key | Does |
|---|---|
| `%` | open a thread (fuzzy) |
| `T` | start a thread on the selected message |
| `t` | toggle main thread / last thread |
| `o` | reply in the last thread used |
| `[t` `]t` | previous / next thread |

![pins](/demo/pins.gif)

| Key | Does |
|---|---|
| `^` | open a pinned message (fuzzy) |
| `:pin` `:unpin` | pin or unpin the selected message |
| `[p` `]p` | previous / next pinned message |
