---
title: Moving around
description: Scroll, jump and find your place.
---

![motions](/demo/motions.gif)

| Key | Does |
|---|---|
| `up` `down` | move the line cursor |
| `J` `K` | next / previous speaker change |
| `[m` `]m` | my previous / next message |
| `[@` `]@` | previous / next mention of me |
| `[l` `]l` | previous / next link or media |
| `f` | a letter on each visible line; type it to select that line |
| `gg` `G` | top, bottom |
| `ctrl+d` `ctrl+u` | half page down / up |

Older history loads when you reach the top.
