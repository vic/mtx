Run it with Nix:

```
nix run github:vic/mtx
```

Or [download](https://github.com/vic/mtx/releases) from releases.

The first run asks for your homeserver and logs you in.
It will generate a key you must save as secret and set as `MTX_PICKLE_KEY`. See [Security](/security).


Press `?` in mtx for every key.
