---
title: Rooms and people
description: Open rooms, message people, invite.
---

![rooms](/demo/rooms.gif)

| Key | Does |
|---|---|
| `#` | pick a channel (fuzzy) |
| `@` | pick a person: enter opens your DM with them |
| `h` `l` | previous / next channel |
| `I` | invite a person to this channel |
| `space c` | channel menu: join, part, mute, tags, members, pins |
| `space C` | room admin: topic, name, kick, ban, op |
| `space p` | people: DM, whois, ignore |
| `space I` | invites to me: list, accept, reject |
| `:dm <user>` | open the direct message with a user |
| `:accept` `:reject` `:invites` | handle invites |
