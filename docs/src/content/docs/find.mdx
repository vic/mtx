title: Find things
description: Search, grep, jump to a date, run commands.
---

![find](/demo/find.gif)

| Key | Does |
|---|---|
| `/` | search: highlights matches |
| `ctrl+g` | grep: show only lines matching the text |
| `S` | show only one speaker |
| `:search <term>` | search this room on the server |
| `:goto <date>` | select the first loaded message at or after a date |
